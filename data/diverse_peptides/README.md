# Diverse peptides example

This folder contains raw CSV files that can be used to recreate the `Diverse peptides` example in peptorama.

To use this data, input the files into the known and monomers section of the upload panel and click `Build network`.

## File overview

| File                   | Description         |
| ---------------------- | ------------------- |
| `diverse_peptides.csv` | One row per peptide |
| `diverse_monomers.csv` | One per row monomer |
