# Diverse peptides example

This folder contains raw CSV files that can be used to recreate the `Antibiotics` example in peptorama.

To use this data, input the files into the known and predicted section of the upload panel and click `Build network`.

## File overview

| File                      | Description         |
| ------------------------- | ------------------- |
| `antibiotics_known.csv`   | One row per peptide |
| `antibiotics_unknown.csv` | One per row monomer |
