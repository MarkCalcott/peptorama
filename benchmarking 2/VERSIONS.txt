benchmarking 1 - tool and database versions
===========================================
Recorded 20 Sep 2026. Every version below was read from the installed tool or
from the provenance stamped inside the data files, not from notes.

Why this file matters: these results are version-sensitive. antiSMASH moves
region boundaries between releases, BiG-SCAPE changes distances, and DiscERN
was run from one specific commit. A rerun on different versions produces a
result, but not this one.

BENCHMARK INPUT (step 3)
------------------------
Python                    3.11.15
Biopython                 1.88
BLAST+                    2.16.0+   (blastp, makeblastdb)

  Thresholds, both defined in the script:
    PVD_NRPS_MIN_ID            45.0 % identity
    PVD_NRPS_MIN_BITS_PER_AA   0.50 bits per query residue
  A synthetase passes on either criterion. Neither alone classifies every
  calibration case correctly: percent identity alone misses P. putida G4R
  PvdJ at 44.3 %, and bits-per-residue alone truncates long synthetases whose
  similarity is unevenly distributed.

PORTABILITY
-----------
None of the scripts hardcode an interpreter, tool path or environment. Each
resolves its tools from PATH and accepts an override:

    BIGSCAPE=/path/to/bigscape  PFAM=/path/to/Pfam-A.hmm  ./run_bigscape.sh
    DISCERN_SRC=/path/to/DiscERN  PY=python3              ./run_discern.sh

Pfam is not shipped (1.5 GB). Fetch and press it with:

    wget https://ftp.ebi.ac.uk/pub/databases/Pfam/current_release/Pfam-A.hmm.gz
    gunzip Pfam-A.hmm.gz && hmmpress Pfam-A.hmm
